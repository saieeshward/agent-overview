## New findings

### A. MAJOR (confidence 0.7): sensitivity inheritance fails open
- Location: register.tsx:441-453 (chainInfo) and :1355-1360.
- An undeclared or exempt (fork, resume, teammate) agent gets undefined sensitivity, so gemini_run with "public" passes.
- Under declare:warn, an undeclared spawn runs.
- `nodes` is capped at 60, so a looping agent can evict its own node.
- adopt() does not retry when agent.list lags.
- Fix: an unresolvable node or a missing declaration counts as internal.

### B. MAJOR (0.8): the Antigravity MCP gate is not public-only
- Location: register.tsx:~1620.
- The mcp__antigravity__* gate calls cloudOk without publicOnly, so internal material reaches Gemini there.
- Fix: publicOnly:true.

### C. MAJOR (0.85): the Bash guard blocks ordinary commands
- Location: agyguard.ts:11-12.
- OBFUSCATED denies `base64 -d`, printf escape codes, `\x1b` in sed/grep, and `xxd -r`.
- The CLI-name regex denies path segments such as `src/<name>.ts`, and any command text that merely mentions the name, together with a confidential path, is refused. This file itself hit that while being written.
- Fix: deny only when decoded output reaches sh/eval. Match the command word, not path segments or arguments.
