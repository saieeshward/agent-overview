1. BLOCKER: register.tsx:736/:441. Sensitivity comes from the tool arg only and is not inherited from the calling subagent's declared sensitivity. A missing value is accepted, and "Client"/"confidential" pass because the check is `=== 'client'`. Repro: a `task:review sensitivity:client` subagent calls gemini_run with sensitivity:"internal" and client text, and it goes to Gemini. Fix: inherit the strictest sensitivity from the parent node's routeLog; accept only exactly public|internal; fail closed.
2. MAJOR: gemini.ts:54 / register.tsx:730. Image paths are string-checked only. No containment to the project; no extension or size check; `cp` follows symlinks (a symlink to client_briefs/a.pdf passes); ~/.ssh/id_rsa passes; /dev/zero fills /tmp. Fix: realpath, regular file, image extension, size cap, under cwd or repo root, and the pattern check on the resolved path.
3. MAJOR: register.tsx:724. The agy Bash regex is easily evaded: `bash -c "agy -p hi"`, `` `agy -p` ``, `A=agy; $A -p`, `agy -p"hi"`, `agy -pm hi`, quoted args, a symlink to agy, and non -p subcommands. Claude-only mode is bypassed the same way. Fix: reuse sideCommand's sh -c unwrapping, or deny agy in Bash outright and allow only gemini_run.
